MiniMind-O 文本推理调用链

只保留定位源码所需的函数和职责，供后续课程快速回看。

入口链路

eval_omni.py
└─ main()
   ├─ argparse 解析参数
   ├─ init_model(args)
   └─ mode == 0
      └─ eval_sample(...)
         ├─ tokenizer.apply_chat_template(...)
         ├─ tokenizer(...)
         └─ MiniMindOmni.generate(stream=True)
            └─ MiniMindOmni.stream_generate(...)
               └─ MiniMindOmni.forward(...)

核心对象

OmniConfig
保存 Thinker、Talker、Projector 和多模态 token 等配置。
MiniMindOmni
整合文本主干、音频生成分支以及音频和视觉输入模块。
Thinker
当前实现中是继承自 MiniMind 的语言模型主干别名。
Talker
根据 Thinker 语义状态逐层生成 Mimi 音频 codes。

输入张量起点

messages: list[dict]
    ↓ apply_chat_template
inputs_text: str
    ↓ tokenizer
input_ids: list[int]
    ↓ torch.tensor(...)[None, ...]
x: LongTensor[1, sequence_length]
